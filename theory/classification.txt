📦 Scikit-Learn Datasets Package
	•	fetch_* functions are used to download real-world datasets (e.g., fetch_openml("mnist_784")).
	•	load_* functions are used to load small toy datasets bundled with Scikit-learn, so there’s no need to download them from the internet repeatedly.
	•	make_* functions are used to generate synthetic (fake) datasets — useful for testing and prototyping.

⚙️ SGD Classifier
	•	SGDClassifier works independently and incrementally.
	•	It is a good choice for online learning, where the model needs to update continuously as new data arrives.
		For each decision it computes a score. If score is greater than threshold, it assigns instance to positive class.

🖼️ Flattening the Images
	•	We must flatten the 2D image matrices into 1D vectors.
	•	Most ML algorithms only understand 1D feature vectors, not 2D image arrays.

📊 Performance Measures

➤ Cross-Validation
	•	Cross-validation splits the training set into multiple folds.
	•	The model is trained and validated on different folds in multiple iterations.
	•	Helps assess the model’s ability to generalize on unseen data.
	•	Avoids over-reliance on a single train/test split.
	•	cross_val_score automates this, returns an array of scores (e.g., accuracy per fold).
	•	The mean of the scores is commonly used as the cross-validation accuracy.

-> Why accuracy is not preferred in Classification
--> By simple example, if we have a digits set. Possibly %90 is not equal to 5. So accuracy is not a direct measurement.
-> Confusion matrix
#-> General idea is count the number of times instances of class A are classified as class B for all A/B pairs.
#-> Precision: How many of your predictions are right?
#-> Precision = True Positives / True Positives + False Positives
#-> Recall & Sensivity: How many of the true positives predicted?
#-> Recall = True Positives / True Positives + False Negatives
#-> F1 Score is the harmonic mean of precision and recall.
#-> Tradeoff: We can define the threshold own by own by using decision_function()
#-> Raising threshold decreases recall. 
-> How to calculate threshold?
#-> Default threshold is 0.
#-> Receiver Operating Characteristic (ROC): plots true positive rate against false positive rate
#-> To compare classifiers, we can focus on area under ROC curve. In ideal classification it equals to 1, on the other hand in random classification it equals to 0.5 (which is corresponding to y=x).
--> We should use PR curve whenever positive class is rare or when you care more about the FP rather than FN

-> To handle multiple choices in classifiers
1-> Multinomal classifiers: which are capable of handling many choices
2-> Training multiple binary classifiers and select highest score
3-> Traning multiple binary classifiers with OvO strategy. It is used to compare two possible results. -make a tradeoff depending on pace of learning phaase.
Note: Scikit automatically detects multiclass classification and runs OvR(OvA) or OvO

-> To handle multilabel operations (like face recognation of many people) use different classifiers.

-> Chain classifier: when we wish to use a classifiers which is not natively support multilabel classification, we organize a chain to make next model to use previous models predictions.
